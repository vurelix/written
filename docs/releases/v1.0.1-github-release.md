A polish release. **Help** is rebuilt as an illustrated, searchable route map, the guided
walkthrough now covers the whole app instead of half of it, and a batch of visual defects from 1.0.0
are fixed.

Your journal file is untouched by this update, and custom dashboard layouts are preserved.

## ❓ Help, rebuilt

Every Help category now opens into an **illustrated route map** — numbered stops along a dotted
path, each opening a focus-managed article. Searchable, one category at a time, fully keyboard
reachable, and it honours `prefers-reduced-motion`. Route labels are set smaller and no longer run
past the edge of the card.

## 🚶 A walkthrough that covers everything

Four steps → **seven**: Dashboard, Calendar, Insights, Playbook, **Profile**, **Settings**, **Help**.

The final step points out that the tour can be replayed and where to find it again — previously it
just ended, with no way back unless you already knew the affordance existed. It lives under
**Help → What does the interactive walkthrough cover? → Replay walkthrough**.

The coachmark no longer flickers into place before it has been positioned.

## 📊 Dashboard

- **Consistency heatmap** ships **full width** with a full **26 weeks** of history, up from 13.
- **This month** gained a row of height.

> [!NOTE]
> Those are *default* sizes. If you had already resized either widget by hand, your layout is kept
> exactly as it was.

## 🎨 Fixes

- Background glow switches off when you turn it off
- Followed checklist rules no longer fade to near-invisible
- Focus rings follow your accent on every surface
- Note tab labels sit centred whether or not the tab has content
- Insights sliders animate from zero on open
- Help article answers have room below the dropdown button
- Installer step numbers are centred, in the UI font rather than the emoji font
- Decorative window dots appear only on macOS in the browser preview — desktop builds unchanged

## 📅 Economic calendar withdrawn

Removed from the dashboard and no longer addable. It was never wired to a real data source, and a
widget full of placeholder events was worse than no widget. It returns if it earns a real feed.

## 📥 Install

**macOS** — `Written-1.0.1-arm64.dmg` (Apple Silicon) or `Written-1.0.1.dmg` (Intel). Drag into
Applications. Ad-hoc signed, **not notarized** — if macOS says *"cannot be opened"* or
*"is damaged"*:

```bash
xattr -dr com.apple.quarantine /Applications/Written.app
```

**Windows** — `Written.Setup.1.0.1.exe`, covering both x64 and ARM64. SmartScreen will warn because
the installer is unsigned: **More info → Run anyway**.

**Upgrading from 1.0.0** — install over the top. Your journal lives outside the app bundle and is
not touched.

## ⚠️ Known limitations

Unsigned builds (both platforms warn on first launch) · Windows untested on real hardware · no
auto-update · screenshots live in the JSON store · CSV export only, no import yet.
