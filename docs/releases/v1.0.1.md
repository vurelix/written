# 📓 Written 1.0.1

A polish release. Help is rebuilt as an illustrated, searchable route map, the guided walkthrough
now covers the whole app instead of half of it, and a batch of visual defects from 1.0.0 are fixed.

Your journal file is untouched by this update, and custom dashboard layouts are preserved.

---

## ❓ Help, rebuilt

Help is no longer a flat list of questions. Every category opens into an **illustrated route map** —
numbered stops along a dotted path, each opening a focus-managed article.

- **Searchable.** Typing reveals the matching category without opening anything.
- **One category at a time**, with the panel tweened open rather than snapping.
- **Fully keyboard reachable**, and honours `prefers-reduced-motion` — transitions stop rather than
  merely shortening.
- Route labels are set smaller and calmer, and the first and last stops now sit far enough inside
  the card that their text can't run over the edge.

## 🚶 A walkthrough that covers everything

The guided tour went from **four steps to seven** — Dashboard, Calendar, Insights, Playbook,
**Profile**, **Settings** and **Help**.

The last step is the important one: it points out that the walkthrough can be replayed, and where to
find it again. Previously the tour ended silently and there was no way back unless you already knew
the affordance existed. You'll find it under **Help → What does the interactive walkthrough cover? →
Replay walkthrough**.

The coachmark also no longer flickers into place — it stays hidden until it has been measured and
positioned, then moves smoothly between steps.

## 📊 Dashboard

- **Consistency heatmap** now ships **full width** and shows a **full 26 weeks** instead of 13 —
  half a year of context at a glance, with cells still large enough to read.
- **This month** gained a row of height.

> [!NOTE]
> These are *default* sizes. If you had already resized either widget by hand, your layout is kept
> exactly as it was — the migration only moves widgets that were still sitting at the old default.

## 🎨 Fixes

- Background glow now actually switches off when you turn it off.
- Followed checklist rules no longer fade to near-invisible.
- Focus rings follow your accent colour on every surface, including overlays outside the app shell.
- Note tab labels sit properly centred whether or not the tab has content.
- Insights sliders animate from zero when the page opens instead of appearing pre-filled.
- Help article answers have room below the dropdown button.
- Installer step numbers are drawn in the UI font and sit centred in their badge. They were being
  rendered through the emoji font, whose metrics pushed the digit off-centre.
- The decorative window dots in the browser preview now appear only on macOS, where they mean
  something. Desktop builds are unchanged: macOS still gets real traffic lights, Windows still gets
  its system title bar.

## 📅 Economic calendar withdrawn

The economic calendar widget is **removed from the dashboard** and can no longer be added. It was
never wired to a real data source, and shipping a widget full of placeholder events was worse than
not shipping it. It'll come back if it earns a real feed.

## 📥 Install

### 🍎 macOS

| Your Mac | Download |
|---|---|
| 🚀 Apple Silicon (M1–M4) | `Written-1.0.1-arm64.dmg` |
| 💻 Intel | `Written-1.0.1.dmg` |

Open the `.dmg`, drag **Written** into **Applications**, and launch it.

Ad-hoc signed but **not notarized**, so macOS may refuse it the first time. If you see *"cannot be
opened"* or *"is damaged"*:

```bash
xattr -dr com.apple.quarantine /Applications/Written.app
```

### 🪟 Windows

Download **`Written Setup 1.0.1.exe`** and run it. SmartScreen will warn because the installer is
unsigned — click **More info → Run anyway**.

One installer covers both **x64** and **ARM64**.

### Upgrading from 1.0.0

Install over the top. Your journal lives outside the app bundle, so nothing is lost:

```
🍎 macOS    ~/Library/Application Support/Written/written-store.json
🪟 Windows  %APPDATA%\Written\written-store.json
```

## ⚠️ Known limitations

Unchanged from 1.0.0:

- **Unsigned builds.** Both platforms warn on first launch.
- **Windows is untested on real hardware.** It builds and packages correctly from macOS, but no
  release has been run on a physical Windows machine. Please open an issue if it misbehaves.
- **No auto-update.** Download future versions manually.
- **Screenshots live in the JSON store**, so it grows with heavy image use.
- **Manual backups only.** CSV export covers trade data, but there is no journal import yet.

## 🛠️ Under the hood

**232 automated tests** — 199 logic tests running the app's logic block in a Node `vm`, and 33
Playwright tests driving the *built* renderer over `file://` so the shipped CSP, layout, focus
behaviour and geometry are all exercised.

Licensed **MIT**, now declared as such in the package manifest and shipped inside the application
bundle alongside the third-party attributions. Bundled components keep their own terms — React,
ReactDOM and Electron (MIT), and the Manrope typeface (SIL OFL 1.1) — reproduced in full under
**About → Open Source**.
